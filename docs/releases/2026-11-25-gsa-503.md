# AltServer / AltStore：2026-11-25 HTTP 503 修复构建

本次构建基于 liuzhe1117/AltStore 的现有 Mac Anisette 分支，同步官方 `classic` 到 `bbc10d6964185b75a46c6ddd7476ac08df095308`，再合入 [AltStore #1875](https://github.com/altstoreio/AltStore/pull/1875) 原始提交 `f4b8c7a10aa858505177f9676a3970cb5bae16ff`。

## 变更

- AltServer 原生 AOSKit 路径的 `X-MMe-Client-Info` 使用 `Mac OS X`，修复 Apple GrandSlam 对 `macOS;` 返回 HTTP 503 的情况。
- 同步上游的手机配对文件管理、后台刷新、Anisette 重置和动态服务器列表。
- 桌面远程 Anisette 改用上游 Keychain 存储，继续绑定服务 URL、Client Info 和 User-Agent，优先使用两个 Mac 服务。
- 保留本 fork 的单次认证身份固定、服务身份展示、无共享容器时的数据库迁移保护及构建链接修复。
- AltSign 同步官方依赖节点 `e639bdfbea185d5c229b11f62e25c5d78649d5c4`，保留本 fork 的身份固定和错误阶段诊断。

## 产物和安装

- `AltServer-503-fix.zip`：AltServer 1.8.2（102），macOS 12+，Universal（arm64 / x86_64），ad-hoc 签名，未公证。
- `AltStore-503-fix.ipa`：AltStore 2.3.1（74），iOS 17.4+，arm64，无个人证书或 provisioning profile，由 AltServer 安装时重新签名。
- `SHA256SUMS.txt`：校验文件。

退出其他 AltServer 后再使用本次桌面构建。通过 Option 点击 AltServer 菜单栏图标，选择 **Sideload .ipa…**，安装本次附带的 IPA。普通 **Install AltStore…** 入口仍按官方配置下载 IPA，不会自动使用本次自编译文件。

只处理电脑端这次请求头问题时，更新 AltServer 是关键。若要使用本次同步的手机配对、认证和后台刷新更新，再覆盖安装附带的 AltStore IPA；不要先卸载现有 AltStore。

手机直接使用 Remote AltServer 时，其 Client Info 和 User-Agent 由所选远程服务提供。#1875 只修复桌面原生路径，不保证解决远程服务的旧身份、`-22410`、`-23782` 或 provisioning 错误。

## 构建

工具链：Xcode 26.3。签名通过构建参数关闭，不写入个人 Team 或本机路径。

```sh
git submodule update --init --recursive
xcodebuild -workspace AltStore.xcworkspace -scheme AltServer -configuration Release -sdk macosx -destination 'platform=macOS' -derivedDataPath /tmp/AltStore-503-build CURRENT_PROJECT_VERSION=102 CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build
xcodebuild -workspace AltStore.xcworkspace -scheme AltStore -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath /tmp/AltStore-503-build CURRENT_PROJECT_VERSION=74 CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build
```

本说明中的临时输出目录仅为命令示例，不属于工程配置。完整 Apple 账号登录、2FA、安装和续签仍需使用者实机验证。
